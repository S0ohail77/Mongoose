A Library that creates connection between MongoDB & Node.js javaScript Runtime Enviorment.

It is and ODM(Object Data Modeling)


here is the way to connect mongoose into javaScript -->

const mongoose = require('mongoose');

main()
.then(() => {
    console.log("Connection successful")
})
.catch((err) => console.log(err));

async function main(){
    await  mongoose.connect('mongodb://127.0.0.1:27017/test'); 
}
